📖 QUY TRÌNH TẠO FILE ĐẦU VÀO SỐ GIẤY CHỨNG NHẬN

Bước 1
Chuẩn bị File Excel đầu vào: File Excel dữ liệu cấu trúc gồm 2 cột xếp liền kề: Cột 1 là STT, Cột 2 là Số GCN. Hàng đầu tiên bắt buộc phải là tiêu đề.
Bước 2
Nạp dữ liệu vào hệ thống: Thực hiện kéo thả file Excel vào vùng màu vàng hoặc bấm trực tiếp vào khung để lựa chọn tệp tin từ máy tính.
Bước 3
Kiểm tra Định dạng tự động: Khi bấm nút "Tiến hành tạo file hàng loạt", hệ thống chạy RAM tự động rà soát từ hàng số 2 trở đi. Mã hiệu phải đúng quy định: 2 ký tự viết hoa + 1 khoảng trắng + 8 chữ số (Ví dụ chuẩn: AA 12345678).
Bước 4
Xuất thành phẩm: Nếu phát hiện lỗi định dạng, hệ thống sẽ chỉ rõ số hàng lỗi để chỉnh sửa. Nếu dữ liệu đạt chuẩn 100%, tệp ZIP chứa hàng loạt file PDF rỗng mang tên và nội dung số hiệu GCN tương ứng sẽ tự động tải xuống.
