📊 Excel: - (0 dòng mã hiệu GCN bắt đầu từ C5)
📄 PDF Mẫu: Chưa chọn

📖 QUY TRÌNH NHÂN BẢN FILE ĐẦU VÀO THEO MẪU

Bước 1
Nạp File Excel danh sách: Chọn tệp Excel chứa dữ liệu, hệ thống tự động nhận diện danh sách mã hiệu GCN bắt đầu từ ô **C5 (Cột C, Hàng 5)** trở đi theo chuẩn định dạng (Ví dụ: AA 12345678).
Bước 2
Nạp File PDF mẫu: Chọn file PDF nguồn chứa nội dung phôi hoặc biểu mẫu ban đầu mà anh muốn nhân bản.
Bước 3
Xử lý tự động: Hệ thống sẽ đọc dữ liệu nhị phân của file PDF mẫu, quét cấu trúc hàng từ hàng số 5 trong file Excel và tiến hành sao chép nhân bản file gốc.
Bước 4
Tải thành phẩm ZIP: File nén ZIP tải về sẽ chứa toàn bộ các file PDF có nội dung giống hệt file mẫu và tên được đổi theo mã hiệu GCN tương ứng lấy ở cột C.
